# 01 · 逆向分析：桌面到底是怎么工作的

> 目标版本：`com.android.launcherWT` 1.8.17.23.release（versionCode 10817230）
> 车机：长安 CS75 PLUS 2020 · 梧桐车机 S311 · Android 4.4.2（API 19）

---

## 1. 整体结构

```
com.android.launcherWT/
├── LauncherApplication        Application，onCreate 只调 super
├── MainActivity               唯一的 Activity（launchMode=singleInstance）
└── R

com.autopai.applist/
├── view/AppsContentView        ★ 整个"桌面"就是这个 View（RecyclerView 网格）
├── manager/AppsManager         应用列表加载 + Package 广播监听
├── manager/AppIconManager      包名 → 图标资源名
├── model/config/AppsConfig     ★ 白名单/标签/主题/属性开关（全部硬编码）
├── model/infos/AppInfo         单个应用的数据结构（含图标加载）
├── model/infos/AllAppsList     列表容器 + 去重
├── adapter/AppListAdapter      RecyclerView 适配器（按 id 排序）
└── model/compat/*              跨版本兼容层（LauncherAppsCompat 等）
```

**关键结论**：`res/layout-land/launcher.xml`（带 Workspace/hotseat 的 Launcher3 布局）是**遗留代码，没有任何地方引用**。
桌面真正使用的是 `res/layout/activity_main.xml` → 只有一个 `<com.autopai.applist.view.AppsContentView/>`。

因此：

- **没有 launcher.db**，桌面布局不落盘；
- 数据目录里只有 `statistics.db`（埋点）和 `shared_prefs`（token）；
- 每次启动都是按白名单**现算**列表。

## 2. 启动链路

```
Application.onCreate()
└ MainActivity.onCreate()
  └ setContentView(R.layout.activity_main)
    └ AppsContentView.init(Context)
      ├ setThemeType()        读主题（classic / sport / simple）
      ├ getCurrentCarType()   读车型（com.incall.proxy，失败会 catch）
      ├ initView()            建 RecyclerView（HorizontalPageLayoutManager(2,5)）
      ├ initData()            ★ 用白名单同步造占位列表
      └ initManager()         new AppsManager → 异步加载真实列表 → adapter.setData()
```

`initData()` 是**最容易崩的地方**，见 [04-避坑指南](04-避坑指南.md)。

## 3. 白名单（核心）

`AppsConfig` 的静态初始化（`AppsConfig$1..$5` 五个匿名内部类）：

```java
// $1：LinkedHashMap<String,String>，包名 → 内置图标资源名
mClassicConfigAppMap.put("cn.kuwo.kwmusiccar", "classic_icon_map");
...
mClassicConfigAppMap.put("com.tencent.wecarspeech/com.tencent.wecarspeech.app.MoreActivity", "classic_icon_speech");

// $2/$3：sport / simple 主题的同款 map（只影响图标，不影响过滤）

// $4：packageNameAppList（中文名，按 map 顺序追加）
// $5：packageEnNameAppList（英文名，同上）

favoritesAppList = new ArrayList<>(mClassicConfigAppMap.keySet());
```

**三张表必须等长同序**，否则 `initData()` 数组越界。

### 过滤逻辑（AppsManager.loadAndBindAllAppsList）

```java
List<LauncherActivityInfoCompat> apps = mLauncherApps.getActivityList(null, user); // 所有带 LAUNCHER 的应用
for (App a : apps) {
    AppInfo appInfo = new AppInfo(context, a, user);
    if (AppsConfig.FILTER_APP_LIST) {
        if ((!mDisableCarTypeList.contains(mCarType) || !mDisableAppsList.contains(pkg))
            && (favoritesAppList.contains(pkg)
                || favoritesAppList.contains(pkg + "/" + cls))) {
            appInfo.id = favoritesAppList.indexOf(pkg);
            if (!mAllAppsList.mListAppIds.contains(appInfo.id)) {   // 去重
                mAllAppsList.mListAppIds.add(appInfo.id);
                mAllAppsList.add(appInfo);
            }
        }
    } else {
        mAllAppsList.add(appInfo);   // 属性开关打开时：全部显示
    }
}
```

排序：`AppListAdapter.sort()` 按 `AppInfo.id`（= 白名单下标）升序 → **桌面位置 = 白名单顺序**。

### 两个额外过滤表

| 表 | 内容 | 作用 |
|---|---|---|
| `mDisableAppsList` | `com.coagent.dvr`、`com.incall.apps.comfortcockpit` | 某些车型隐藏这两个应用 |
| `mDisableCarTypeList` | CARTYPE_1..9、11..14（无 10） | 哪些车型启用上面的隐藏 |

本机车型 `CHANGAN_S311_CARTYPE_8` 在列表里 → 行车记录仪、舒适座舱被隐藏。

### 属性开关

```java
FILTER_APP_LIST = !"1".equals(getprop("sys.thirdapk.caninstall"));
```

`sys.thirdapk.caninstall=1` 时**不过滤**，所有应用都显示（重启失效，是内存属性）。

## 4. 图标

```java
// AppInfo 构造（真实列表走这个）
String name = AppIconManager.getAppIconResourcesId(pkg, cls);  // 查白名单 map
int id     = Utilities.getResourcesID(context, name, "drawable");
iconDrawable = id > 0 ? context.getResources().getDrawable(id)  // 桌面内置图
                      : mInfo.getBadgedIcon(240);               // 应用自己的图
```

- map 值为 `""` → 回落应用自己的图标；
- map 值给了资源名 → 用桌面内置图标（要求资源存在）；
- 内置图标规格：**136×136 PNG**，位于 `res/drawable/` 和 `res/drawable-land-hdpi-v4/`。

详见 [03-图标定制](03-图标定制.md)。

## 5. 与厂商系统的交互

| 依赖 | 用途 | 失败后果 |
|---|---|---|
| `com.incall.proxy`（uses-library，required=false） | 车型、主题、空调等 | 已 try-catch |
| `SettingServiceManager` | 主题监听 | 已 catch |
| `com.wt.statistics` | 埋点上报 | 不影响 UI |
