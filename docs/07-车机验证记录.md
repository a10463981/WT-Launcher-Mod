> 记录时间：2026-11-11
> 车机：长安 CS75 PLUS 2020 · 梧桐车机 S311 · Android 4.4.2

## 一、结论

| 版本 | 基线 | 真车结果 |
|---|---|---|
| **WT_Launcher_C2_verified.apk** | 车机现装 **1.8.17.23**（10817230） | ✅ **验证通过，桌面正常** |

## 二、失败原因分析

### 失败的版本做了什么

1. 基线换成原厂 OTA 里的 `S311WT_Launcher.apk`（**1.8.17.15**，比车机现装的 1.8.17.23 **旧**）
2. 为了让系统接受"降级"安装，把 `AndroidManifest.xml` 的 `versionCode` 从 10817150 改成了 108172xx

### 为什么黑屏

两个可疑点（都指向"不要动清单"）：

| 可疑点 | 说明 |
|---|---|
| **改了 AndroidManifest.xml** | 修改清单会改变 APK 的字节内容。车机 ROM 带"为辰加密"安全框架，可能对系统 APK 做完整性校验；清单被改 → 包被拒 → 没有桌面 → 黑屏 |
| **1.8.17.15 与系统不匹配** | 车机实际跑的是 1.8.17.23，OTA 包里的 1.8.17.15 是更早的版本，可能调用了已变更的厂商接口 |

### 成功的版本做了什么

- 基线：**车机上正在运行的那份 APK**（1.8.17.23）
- 改动：`classes.dex` + 7 张 PNG
- `AndroidManifest.xml`、`resources.arsc`、`META-INF` **全部逐字节保持原样**

## 四、车机安装步骤（已验证）

```
1. 备份：/system/app/WT_Launcher.apk → /sdcard/WT_Launcher_backup.apk
2. 用 ES(root) 把 WT_Launcher_C_carbase.apk 复制进 /system/app/
3. 改名为 WT_Launcher.apk 覆盖
4. 权限设为 644（rw-r--r--）
5. 重启车机
```

---

## 五、以后必须遵守的规则

1. **基线必须是车机上正在运行的那个 APK**，不要用 OTA 包里的旧版本；
2. **永远不要修改 `AndroidManifest.xml`**（包括 versionCode）；
3. **不要改 `resources.arsc`**，图标只替换同名 PNG 文件；
4. **不要动 `META-INF`**（保留原厂签名）；
5. 只重建 `classes.dex`；
6. 换之前先备份，出问题用备份覆盖回去。
