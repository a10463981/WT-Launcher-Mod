# 02 · 如何添加白名单应用

---

## 一、三张表，必须同时改

| 文件 | 内容 | 约束 |
|---|---|---|
| `smali/com/autopai/applist/model/config/AppsConfig$1.smali` | 包名 → 图标资源名（LinkedHashMap） | 主表，决定**过滤**和**顺序** |
| `AppsConfig$4.smali` | 中文名（`packageNameAppList`） | 长度必须与 `$1` 相同 |
| `AppsConfig$5.smali` | 英文名（`packageEnNameAppList`） | 长度必须与 `$1` 相同 |

**顺序决定桌面位置**：`favoritesAppList` 来自 `$1` 的 keySet，`sort()` 按 `id = indexOf(pkg)` 升序排列。

> 注意：`$4` / `$5` 只用于启动瞬间的占位渲染，真实列表的标签来自应用自身。

---

## 二、加一条：改三处

### 1. `AppsConfig$1.smali`

找到 `return-void` 前的位置，追加：

```smali
const-string v0, "com.shihab.diplay"
const-string v1, "classic_icon_applet"
invoke-virtual {p0, v0, v1}, Lcom/autopai/applist/model/config/AppsConfig$1;->put(Ljava/lang/Object;Ljava/lang/Object;)Ljava/lang/Object;
```

- 第二个参数是**图标资源名**：填 `""` 表示用应用自己的图标；填 `classic_icon_xxx` 表示用桌面内置图标。
- 多个包可以共用同一个图标资源名。

### 2. `AppsConfig$4.smali`（中文名）

```smali
const-string v0, "CarPlay"
invoke-virtual {p0, v0}, Lcom/autopai/applist/model/config/AppsConfig$4;->add(Ljava/lang/Object;)Z
```

### 3. `AppsConfig$5.smali`（英文名）

```smali
const-string v0, "CarPlay"
invoke-virtual {p0, v0}, Lcom/autopai/applist/model/config/AppsConfig$5;->add(Ljava/lang/Object;)Z
```

```
classic_icon_user_center      classic_icon_vehicle_setting
```

**没被任何应用占用的"空位"**：


## 四、完整示例

### 需求

把 CarPlay（`com.shihab.diplay`）、QQ音乐（`com.wt.music`）、腾讯地图（`com.tencent.wecarnavi`）加到桌面。

### 改动

`AppsConfig$1.smali` 的 `return-void` 前：

```smali
const-string v0, "com.shihab.diplay"
const-string v1, "classic_icon_applet"
invoke-virtual {p0, v0, v1}, Lcom/autopai/applist/model/config/AppsConfig$1;->put(Ljava/lang/Object;Ljava/lang/Object;)Ljava/lang/Object;
const-string v0, "com.wt.music"
const-string v1, "classic_icon_music"
invoke-virtual {p0, v0, v1}, Lcom/autopai/applist/model/config/AppsConfig$1;->put(Ljava/lang/Object;Ljava/lang/Object;)Ljava/lang/Object;
const-string v0, "com.tencent.wecarnavi"
const-string v1, "classic_icon_user_center"
invoke-virtual {p0, v0, v1}, Lcom/autopai/applist/model/config/AppsConfig$1;->put(Ljava/lang/Object;Ljava/lang/Object;)Ljava/lang/Object;
```

`AppsConfig$4.smali`：

```smali
const-string v0, "CarPlay"
invoke-virtual {p0, v0}, Lcom/autopai/applist/model/config/AppsConfig$4;->add(Ljava/lang/Object;)Z
const-string v0, "QQ音乐"
invoke-virtual {p0, v0}, Lcom/autopai/applist/model/config/AppsConfig$4;->add(Ljava/lang/Object;)Z
const-string v0, "腾讯地图"
invoke-virtual {p0, v0}, Lcom/autopai/applist/model/config/AppsConfig$4;->add(Ljava/lang/Object;)Z
```

`AppsConfig$5.smali` 同理（英文名）。

### 结果

白名单 15 → 18 条，桌面多 3 个图标（前提：这 3 个应用已安装）。

## 五、常见错误

| 错误 | 后果 |
|---|---|
| 只改 `$1` 不改 `$4/$5` | `initData()` 越界 → **黑屏** |
| `$4/$5` 数量对但顺序错 | 占位列表标签错乱（几十毫秒后恢复正常） |
| 图标名写错 | 查不到 → 回落应用自己的图标（不会崩） |
| 图标名指向不存在的资源 | 同上 |
| 包名写错（多空格/大小写） | 该应用不显示，不会崩 |
