# 03 · 图标定制

---

## 一、图标是怎么找的

```java
// AppInfo 构造（真实列表）
String name = AppIconManager.getAppIconResourcesId(pkg, cls);
int id = Utilities.getResourcesID(context, name, "drawable"); // getIdentifier
iconDrawable = id > 0 ? context.getResources().getDrawable(id) // 桌面内置
                      : mInfo.getBadgedIcon(240);              // 应用自己的
```

所以白名单 map 的值有两种写法：

| 写法 | 效果 | 适用 |
|---|---|---|
| `""` | 用**应用自己的图标**（系统按 240dpi 取图，通常偏大） | 应用有图标且不在乎大小 |
| `"classic_icon_xxx"` | 用**桌面内置 136×136 图标** | 想要统一风格、大小一致 |

**推荐用内置图标**——应用自带的图标在车机上会明显偏大，破坏版式。

---

## 二、内置图标的规格

```
位置：res/drawable/classic_icon_xxx.png
      res/drawable-land-hdpi-v4/classic_icon_xxx.png   ← 横屏 hdpi 优先用这个

尺寸：136 × 136
格式：PNG（透明背景）
内容：约 74~96 px 居中，四周留透明边
```

从原厂图标量出来的内容框：

| 图标 | 内容尺寸 | 偏移 |
|---|---|---|
| `classic_icon_phone` | 74×74 | 31,31 |
| `classic_icon_file_manager` | 81×71 | 28,33 |
| `classic_icon_music` | 41×88 | 47,24 |
| `icon_amap` | 88×88 | 24,24 |

**制作规范**：96×96 内容居中放在 136×136 画布上（四周 20px 透明边），需要圆角就加 22px 圆角。

## 三、怎么"添加"自己的图标

> Android 的资源名在 `resources.arsc` 里编译死了。**新增资源名要重编译资源表**，风险高（apktool 重建后可能和车机固件不兼容）。
>
> **正确做法**：复用已有的资源名，替换它的 PNG 内容。

### 步骤

**1. 选一个没被占用的图标名**

```
classic_icon_applet
classic_icon_instructions
classic_icon_maintain
classic_icon_user_center
classic_icon_soft_manager_red
```

**2. 把图片做成 136×136**

```bash
# 普通图（需要圆角）
convert logo.png -strip -resize 96x96 \
  \( -size 96x96 xc:black -fill white -draw "roundrectangle 0,0,95,95,22,22" \) \
  -alpha off -compose CopyOpacity -composite \
  -background none -gravity center -extent 136x136 \
  -strip PNG32:out.png
```

**3. 替换 APK 里的同名文件**（用 zip 直接替换，**不要用 apktool 重建资源**）

```python
import zipfile
with zipfile.ZipFile('WT_Launcher.apk') as z, zipfile.ZipFile('out.apk','w') as o:
    for it in z.infolist():
        data = open('out.png','rb').read() if it.filename == 'res/drawable/classic_icon_applet.png' else z.read(it.filename)
        o.writestr(it, data)
```

> 原 APK 里这些 PNG 是 **STORED（未压缩）**，替换后需要用 `zipalign -f 4` 重新对齐。

**4. 白名单 map 指向它**

```smali
const-string v1, "classic_icon_applet"
```

## 四、圆角处理（踩过的坑）

ImageMagick 有几个写法会把图片弄成灰度/黑色，**只有这个写法是正确的**：

```bash
convert input.png -strip -resize 96x96 \
  \( -size 96x96 xc:black -fill white -draw "roundrectangle 0,0,95,95,22,22" \) \
  -alpha off -compose CopyOpacity -composite \
  -background none -gravity center -extent 136x136 \
  -strip PNG32:output.png
```

要点：

- 掩膜用 `xc:black` + 白色圆角矩形（黑白灰度图）
- `-alpha off -compose CopyOpacity`（**不是** `DstIn`，那个会丢颜色）
- 输出用 `PNG32:` 强制 RGBA，否则可能变成灰度图

验证：

```bash
convert out.png -format "center=%[pixel:p{68,68}] corner=%[pixel:p{2,2}]\n" info:
# 期望：center 是颜色，corner 是 srgba(0,0,0,0)
```

## 五、官方 logo 从哪来

| 来源 | 说明 |
|---|---|
| 应用 APK 本身 | `aapt2 dump badging app.apk \| grep application-icon`，取最高密度那张，最准确 |
| Apple App Store 图标 | `https://itunes.apple.com/search?term=<名称>&country=cn&entity=software` → `artworkUrl512`（512×512） |
| 官网 favicon | 通常只有 32~64px，放大后发虚，不推荐 |

本项目用到的图标：

| 应用 | 来源 |
|---|---|
| QQ音乐 | App Store 512×512 |
| 酷我音乐 | App Store 512×512 |
| 喜马拉雅 | App Store 512×512 |
| 腾讯视频 | `vfiles.gtimg.cn` 官方 192×192 |
| 腾讯地图 | 车机版 APK 内 `ic_launcher.png` 192×192 |
| CarPlay | DiPlay APK 内 `ic_carplay.png` 192×192 |

## 六、原厂图标错配（可顺手修）

原厂 `AppsConfig$1` 里前三个槽位和包名对不上：

| 包名 | 原厂图标 | 实际应显示 |
|---|---|---|
| `cn.kuwo.kwmusiccar`（酷我） | `classic_icon_map`（地图） | 酷我音乐 |
| `com.ximalaya.ting.android.car`（喜马拉雅） | `icon_music`（音符） | 喜马拉雅 |
| `com.tencent.qqlivepad`（腾讯视频） | `classic_icon_radio`（电台） | 腾讯视频 |

直接替换这三个 PNG 的内容即可修正。
