## 一、为什么要换基线

之前一直用的"原厂包"来自车机 `/system/app/WT_Launcher.apk`（1.8.17.23），
但对比真原厂 OTA 包后发现**车机那份已被第三方改过**。

| # | 真原厂 OTA（1.8.17.15） | 车机现装（1.8.17.23） | 说明 |
|---|---|---|---|
| 1 | `com.tencent.wecarnavi` 腾讯地图 | `cn.kuwo.kwmusiccar` 酷我 | 包名被换，标签没换 |
| 2 | `com.wt.music` QQ音乐 | `com.ximalaya.ting.android.car` 喜马拉雅 | 同上 |
| 3 | `com.tencent.wecarnews` 腾讯车载电台 | `com.tencent.qqlivepad` 腾讯视频 | 同上 |
| 4-8 | vlink / 空调 / 高德 / 电话 / DVR | 相同 | — |
| 9 | `comfortcockpit` 舒适氛围 | `vehiclesetting` 车辆设置 | 顺序互换 |
| 10 | `setting` 系统设置 | 相同 | — |
| 11 | `vehiclesetting` 车辆设置 | `comfortcockpit` 舒适氛围 | 顺序互换 |

**证据**：车机版前三个槽位的标签仍是"腾讯地图/QQ音乐/腾讯车载电台"，与包名不匹配 →
典型的"改包名不改标签"手工修改痕迹。

## 二、本次改造内容

### 新增 5 条白名单（原厂 14 条一条未动）

| # | 包名 | 标签 | 图标 |
|---|---|---|---|
| 15 | `cn.kuwo.kwmusiccar` | 酷我音乐 / Kuwo Music | `classic_icon_music`（替换为酷我 logo） |
| 16 | `com.ximalaya.ting.android.car` | 喜马拉雅 / Ximalaya | `classic_icon_applet`（替换为喜马拉雅 logo） |
| 17 | `com.shihab.diplay` | DiPlay / DiPlay | `classic_icon_user_center`（替换为 CarPlay logo） |
| 18 | `com.estrongs.android.pop` | ES文件浏览器 / ES File Explorer | `classic_icon_file_manager`（原厂文件管理图标） |
| 19 | `com.tencent.wecarspeech` | 语音设置 / Voice Setting | 空（用应用自己的图标） |

最终三张列表：**19 / 19 / 19**，等长同序。

### 图标

替换了 6 个 PNG（`res/drawable/` 与 `res/drawable-land-hdpi-v4/` 各 3 张）：

```
classic_icon_music.png       ← 酷我音乐官方图标（136×136、22px 圆角）
classic_icon_applet.png      ← 喜马拉雅官方图标
classic_icon_user_center.png ← CarPlay 图标
```

### 两个 NPE 修复

1. **`AppInfo` 4 参构造**：查不到内置图标时直接置空，不调用 `mInfo.getBadgedIcon()`
   （原厂代码 `v2/v3` 寄存器，已适配）
2. **`Utilities.getResourcesID`**：`idname == null` 时返回 0
   （主题非 classic 时 `map.get()` 返回 null 会触发）

### versionCode

原厂 `10817150` < 车机现装 `10817230`，直接替换有**降级风险**。
已把 versionCode 改为 **10817240**（仅改这一个整数，manifest 字节数不变）。

## 五、安装

```
1. 备份车机 /system/app/WT_Launcher.apk → /sdcard/WT_Launcher_backup.apk
2. 用 ES(root) 把本 APK 复制进 /system/app/
3. 改名为 WT_Launcher.apk 覆盖
4. 权限设为 644 (rw-r--r--)
5. 重启车机
```

> 注意：这是**原厂 1.8.17.15** 的改造版，桌面应用集合会回到原厂 14 个 + 新增 5 个。
> 与车机原来那份"第三方改版"（酷我/喜马拉雅/腾讯视频/ES/语音设置）不同。

## 六、剩余风险

1. **车机签名校验**：模拟器无法验证，但用的是原厂证书，理论上必过；
2. **固件版本差异**：只对 1.8.17.15 这条基线保证；车机若刷了别的版本需重新适配；
3. **降级覆盖**：若车机的 PackageManager 仍拒绝（极少数情况），需要先 `pm uninstall` 或删除 `/data/app` 下的更新包；
4. **主题 map**：sport/simple 主题下新应用图标会回落成应用自身图标（功能正常）。
